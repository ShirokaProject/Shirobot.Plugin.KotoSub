# KotoSub

[ShiroBot](https://github.com/ShirokaProject/ShiroBot) 的订阅推送插件。订阅 RSS / Atom 源，有新内容时推送到群聊或私聊。

Bilibili、X、GitHub、Gitea、WordPress 有专属卡片。

## 安装与使用

本项目遵循 [ShiroBot 插件开发规范](https://docs.shiroka.org/plugin/)，安装、构建、部署、调试与发布请参考官方文档。要求宿主 1.0.0 及以上。

命令与配置见[项目说明](Shirobot.Plugin.KotoSub/README.md)。
